Wechselspiel zwischen den Schichten
• Interaktion der Schichten
• Eine Schicht bietet der über ihr liegenden Schicht Dienste an
• Um dies zu realisieren versieht sie ihre Nachricht mit Kontrollinformationen (Header) und 
versendet alles zusammen (oftmals Protocol Data Unit (PDU) genannt)
• Zwei Kommunikationspartner gleichen Schicht nutzen die Information der Header um die 
Funktionalitäten zu erzielen
• Die PDU einer Schicht n wird an die Schicht (n-1) geleitet, dort sind dies die zu 
übertragenden Inhaltsdaten
• In unteren Schichten muss ein Upper-Layer-Protocol-Feld eingefügt sein, damit die passende 
obere Schicht ausgewählt werden kann, die die Nutzdaten passend in Header und Inhalt 
aufsplitten kann
• Eine obere Schicht muss die untere Schicht parametrisieren
Merke: Schicht 2 wird hiervon abweichen. Tatsächlich findet hier ein Framing statt, welches 
Fehlererkennung/-korrektur und Synchronisation (wo ist die Nachricht sicher zu Ende) vereinfacht

• Schicht  7: Anwendungsschicht (Application Layer)

Aufgaben der Schichten
• Schicht  6: Darstellungsschicht (Presentation Layer)
• Beschäftigt sich damit, die zu übertragenden Daten so darzustellen, dass sie von 
unterschiedlichen Plattformen und Anwendungen gehandhabt werden können
• Beispielsweise codieren manche Programme einen String mit ASCII-Zeichen, andere 
benutzen Unicode, manche benutzen 32-Bit Größen, andere 64. Problematisch ist auch 
die Byteordnung des Prozessors (Big/Little-Endian)
• Binäre Daten können Sonderzeichen enthalten, die je nach Verarbeitungsprogramm zu 
Seiteneffekten führen
• Formal wird hier das verwendete Format beschrieben werden- Anstatt für jede Anwendung eine eigene Übertragungssyntax und -semantik zu definieren, stellt 
man mittels der Schicht eine allgemeingültige Lösung bereit- Die spezifischen Daten eines Rechners werden hier eindeutig beschrieben
Merke: Eine effiziente plattformunabhängige Darstellung ist zwingend erforderlich.

• Dialogkontrolle, d.h. es kann festgelegt werden, welcher Kommunikationspartner wann

Aufgaben der Schichten
• Internet-Schicht (entspricht ISO/OSI 3)
• Aufgabe dieser Schicht: Kommunikation zwischen Rechnern auch über die eigenen 
Netzwerkgrenzen hinaus. Die dabei gewählte Übertragungstechnik ist paketvermittelnd, 
d.h. die Datagramme werden unabhängig voneinander mit Adressinformation versehen 
vom Sender losgeschickt
• Im Netz findet ein Store-and-Forward statt. An der Grenze zwischen zwei Netzen sorgen 
Router für die Weiterleitung der Daten. Nach dem Empfang findet die Entscheidung über 
den nächsten Router konzeptionell anhand der Zieladresse statt.
• Datagramme/Pakete können demnach im Netz verloren gehen oder beim Empfänger in einer 
anderen Reihenfolge ankommen als sie abgesendet wurden. Die Behebung solcher Situation ist 
der Transportebene vorbehalten
• Ein wesentlicher Vorteil ist, dass eine „Leitung“ (ein Netz) von vielen Teilnehmern genutzt werden 
kann, jeweils zur Übertragung eines Datagramms. Dann kann ein anderer Teilnehmer übertragen.
• Festlegung eines einheitlichen Protokolls zur Kopplung aller Netze im Internet samt 
Paketformat: das Internet Protocol (IP)

Aufgaben der Schichten
• Transportschicht (entspricht ISO/OSI 4)
• Kümmert sich um die Kommunikation zwischen Anwendungen. Definiert sind zwei 
unterschiedliche Ende-zu-Ende Protokolle:- TCP (Transmission Control Protocol), ein zuverlässiges, verbindungsorientiertes Protokoll, 
welches einen Strom von Bytes sicher zwischen zwei Rechnern überträgt. Dazu wird der Strom 
segmentiert und in IP-Pakete verkapselt. Auf der Gegenseite werden die ankommenden Pakete 
in der richtigen Reihenfolge zusammengesetzt, so dass der ursprüngliche Datenstrom entsteht. 
TCP sorgt u.a. auch für Flusskontrolle, damit der Sender den möglicherweise langsameren 
Empfänger nicht überlastet und so seine Senderate reduziert. Es wird auch eine Staukontrolle 
implementiert, um so Überlast zu vermeiden.- UDP (User Datagram Protocol), ein unzuverlässiges (“best effort”) und verbindungsloses 
Protokoll. UDP wird benutzt, wenn z.B. eine schnelle Lieferung der Daten wichtiger ist als eine 
absolut zuverlässige (Sprache, Video).

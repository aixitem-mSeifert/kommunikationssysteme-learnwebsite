MTU (Programm)
Einen Lösungsvorschlag findet man unter https://git.fh-aachen.de/kommunikationssysteme/mtu. Mögliche Fehler bitte weiterleiten.
Schreiben Sie ein Programm, dass eine MTU-Fragmentierung simuliert. Es empfiehlt sich Maven zu benutzen z.B. für JUnit-Dependency (siehe unten).

Dazu erstellen Sie die drei Klassen:

Packet
Route
Simulation
Packet
In Packet werden nur die folgenden vier Attribute gehalten:

String ID
boolean mf
int payload
int offset
Und eine Methode:

public String toString()
Bei dieser Klasse bietet es sich an eine record class zu verwenden.

Route
Route besitzt zwei Attribute:

private final int MTU
private final int maxSize (die maximal mögliche Größe als Vielfaches von 8, kann identisch sein mit der MTU)
Drei Methoden:

public Route(int mtu)
String toString()
List<Packet> processPacket(Packet packet)
Die Methode processPacket erhält ein Eingangspaket und gibt 1 bis n Ausgangspakete in einer Liste zurück.
Dementsprechend wird hier die eigentliche Logik der Fragmentierung implementiert

@Test
public void testProcessPackage() {
    List<Packet> packets = new Route(2000).processPacket(new Packet("x", false, 4200, 0));
    assertEquals(3, packets.size());
    assertEquals("x", packets.get(0).ID());
    assertTrue(packets.get(0).mf());
    assertEquals(1976, packets.get(0).payload());
    assertEquals(0, packets.get(0).offset());
    assertEquals("x", packets.get(1).ID());
    assertTrue(packets.get(1).mf());
    assertEquals(1976, packets.get(1).payload());
    assertEquals(1976, packets.get(1).offset());
    assertEquals("x", packets.get(2).ID());
    assertFalse(packets.get(2).mf());
    assertEquals(248, packets.get(2).payload());
    assertEquals(3952, packets.get(2).offset());
}

Server
Aufgabe
In diesem Praktikum wollen wir einen UDP-DNS-Mockup-Server erstellen. (Natürlich wird der DNS-Server nicht ausprogrammiert, sondern nur angedeutet.)

Der Server läuft wie folgt:

Start des UDP-Servers auf einem freien Port mit DatagramSocket(int) mit anschließender Endlosschleife.

Einlesen eines DatagramPackets mit DatagramPacket(byte[], int) und DatagramSocket.receive(DatagramPacket), die Paketgröße sei 1024.

Aus diesem DatagramPacket folgendes auslesen:

übermittelter String (getData())
übermittelter Client-Port (getPort())
übermittelte Client-Adresse (getAddress())
oder direkt SocketAddress (getSocketAddress())
Aus einer vorher erstellten und befüllten HashMap<String, String> (Key: DNS-Name, Value: IP-Adresse) mit dem übermittelten String (DNS-Name) die entsprechende IP ermitteln.
Unbekannte Namen liefern null zurück, in dem Fall soll die IP "unbekannt" lauten.

Die ermittelte IP-Adresse als neues DatagramPacket zurück schicken.

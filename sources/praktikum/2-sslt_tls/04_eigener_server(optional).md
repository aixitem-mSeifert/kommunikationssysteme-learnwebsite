Eigener Server (optional)
Stellen Sie Ihr eigenes Echoserverprojekt auf SSL/TLS um. Nutzen Sie dafür zunächst die von Ihnen gerade erstellten KeyStore-Dateien.

Hierfür eignet sich ein neuer Git-Branch!

Diese Aufgabe muss nicht abgegeben werden. Denken Sie aber daran (für den Fall der Fälle): Geben Sie keinen Keystore ab, der einen private key enthält!
